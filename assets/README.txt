Drop your images into this folder with these exact filenames:

  logo-mark.png         — square logo for nav + footer (recommended 64x64 or 128x128, transparent PNG)
  favicon.png           — browser tab icon (32x32 or 64x64)
  og-image.png          — social share card image (1200x630, used when sharing on Twitter/Discord/etc.)

  screenshots/main.png      — hero image, the big main app screenshot (the one with the full table view)
  screenshots/search.png    — the search/filter screenshot
  screenshots/tagging.png   — the tagging/collections screenshot

The site uses onerror fallbacks, so if a file is missing the slot shows a "drop screenshot here" placeholder
instead of a broken image — safe to deploy before all assets are in place.

For the logo, the orange-on-black play-button mark from your branding works perfectly. Export it as a
transparent PNG and you're done.
