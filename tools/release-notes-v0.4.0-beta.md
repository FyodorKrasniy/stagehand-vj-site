# Stagehand VJ Beta (r34)

Latest beta build of **Stagehand VJ Clip Manager**.

The same binary works as both the free demo and the licensed app — entering a licence key from **Help → License…** removes the demo's batch-export cap. Buy a licence at [stagehandvj.com](https://stagehandvj.com).

## Downloads

| Platform | File | Size |
|---|---|---|
| Windows 10/11 x64 | `StagehandVJ-Beta-WinSetup_r34.exe` | ~200 MB |
| macOS Apple Silicon (M1/M2/M3) | `StagehandVJ-Beta-arm-x64.zip` | ~105 MB |
| macOS Intel | `StagehandVJ-Beta-osx-x64.zip` | ~105 MB |

Mac builds are Apple Developer ID signed, notarized, and stapled — Gatekeeper accepts on first launch, no right-click-Open dance.

## Demo limits

- Metadata tagging / editing / export is limited to **10 distinct files per app session**
- Metadata export runs **one file at a time** (no batch export)

Everything else — tagging, rating, search, collections, preview, codec detection, Resolume drag-and-drop, REST API integration — works without limits.

## Install

**Windows:** Run the installer. Per-user install to `%LOCALAPPDATA%` — no admin rights needed.
**Mac:** Double-click the zip, drag `Stagehand VJ.app` to `/Applications`.

Settings + database survive reinstalls.
